# Project Name

This is a Dash-based dashboard project.

## Clone the repository

```bash
git clone <https://github.com/aregmelqonyan/Loan-Dashboard>
cd <Loan-Dashboard>

# Windows
python -m venv venv
venv\Scripts\activate

# macOS / Linux
python3 -m venv venv
source venv/bin/activate

pip install -r requirements.txt

python app.py
```

## Go to: http://127.0.0.1:8050/ to access the dashboard.
